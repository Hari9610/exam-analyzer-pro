## Deploy
Upload the contents of this ZIP into the root of your existing GitHub Pages repository, replacing the old `index.html` and adding the `data/` and `results/` folders. Keep `manifest.webmanifest` and `sw.js` at the repository root.

## Important static-site limitation
GitHub Pages is static hosting. It does not provide a secure shared Admin Upload that writes files for all visitors. This build publishes a prepared JSON index and the official source PDF. To add another result, prepare a new JSON index and commit it to the repository. Do not upload private or non-public candidate data.

## Source and status
Source: RSSB Basic Computer Instructor Direct Recruitment 2026 Result and Cutoff PDF dated 04-11-2026. The result is provisional. Cutoff comparisons are informational and do not establish final selection or appointment. Candidate names and family details are not displayed in the public lookup.
