Exam analysis, with checks at every step.

Upload a question paper, your marked OMR and the official answer key. Review uncertain readings, configure the exam's published marking rules, and generate an auditable score report. Candidate records can be matched against a result PDF or a verified roster you provide.

Accuracy note: no OCR or document parser is infallible. This tool never claims government identity verification. A match means only that the supplied documents contain matching fields. Review low-confidence or conflicting data before relying on a result.

How to use

  1. Choose board and enter the exam name.
  2. Enter the exact Paper Code / Booklet Series shown on the paper and confirm the matching official key.
  3. Set positive and negative marks from the official notification.
  4. Upload source files for your own reference.
  5. Manually enter the official key and your marked OMR responses question by question (A–E). Automatic bubble reading is not used.
  6. Review the calculation and export the report.
  7. For candidate lookup, upload a searchable result PDF and search by exact Roll Number. Add a verified CSV only if Application Number matching is required.

Privacy & security

  • Files are not sent to a server by this static website.
  • Do not upload Aadhaar, passwords, bank details or unnecessary personal data.
  • Use only public/authorized result data and obtain consent before processing personal records.
  • Do not represent a local match as an official government verification.
  • Offline mode works after the website assets have been cached once by a supported browser.

What is not implemented yet

Automatic OCR of question papers and result PDFs, automatic OMR bubble detection, secure multi-user admin login, cloud sync and live government portal/API verification are not included. These require additional tested services and cannot be honestly represented as complete here.
