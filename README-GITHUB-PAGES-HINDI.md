# Exam Analyzer Pro — Hari Meena

## GitHub Pages par free public website banane ke steps

1. GitHub par login karein: https://github.com/
2. **New repository** par click karein.
3. Repository name rakhein: `exam-analyzer-pro` aur visibility **Public** rakhein.
4. Is ZIP ko extract karein. `index.html`, `manifest.webmanifest`, `sw.js` aur `.nojekyll` ko repository ke main/root page par upload karein — folder ke andar nahi.
5. **Commit changes** karein.
6. Repository me **Settings → Pages** kholein.
7. **Build and deployment** me Source: **Deploy from a branch** chunein.
8. Branch: **main** aur folder: **/(root)** select karke **Save** karein.
9. Kuch minute baad Pages section me aapka public website URL aa jayega. Use mobile par kholkar test karein.
